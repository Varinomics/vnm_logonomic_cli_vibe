# Mistral Vibe CLI add-on for Logonomic

Native Logonomic CLI add-on for [Mistral Vibe](https://github.com/mistralai/mistral-vibe).

The integration is being implemented against Logonomic's public CLI add-on SDK
and Mistral Vibe's native session and agent hooks (available from Vibe 3.1.1).
The initial scope is launcher discovery, managed launch configuration, exact
session resume, lifecycle reporting and native session data.

Implementation and qualification are developed in incremental commits. See the
implementation pull request for progress and the capabilities actually supported.
